mini_dash_tui: 초저부하 서버 관리 TUI

========================================================================

1. 프로젝트 개요

mini_dash_tui는 초저부하로 동작하는 서버 관리용 터미널 사용자 인터페이스(TUI)입니다.
별도의 웹 서버나 브라우저 없이 터미널(curses)만 사용하며, CPU, GPU, RAM, 디스크 사용량 및 사용자별 Python/IPyNB 프로세스 현황을 모니터링합니다. 기본 갱신 주기는 5초입니다.

------------------------------------------------------------------------

2. 주요 기능 및 특징

- 실시간 리소스 모니터링 (CPU, RAM, SWAP, DISK)
- NVML을 통한 GPU 상세 정보 및 사용자별 VRAM 사용량 집계
- 사용자별 Python 및 IPyNB 커널 프로세스 카운트
- 목록에서 PID를 선택하여 SIGTERM, SIGKILL, SIGINT 시그널 전송 기능 제공

- [권한] 타 사용자 프로세스를 kill하려면 반드시 'sudo' 권한으로 실행해야 합니다.

------------------------------------------------------------------------

3. 의존성 (Dependencies)

- 필수: psutil
- 선택: pynvml (GPU 정보 사용 시 필요)

------------------------------------------------------------------------

4. 실행 방법

1) 종속성 설치 후 (Conda 환경 권장)

2) 일반 실행 (모니터링 및 본인 프로세스 관리)
$ python mini_dash_tui.py

3) 관리자 권한으로 실행 (타 사용자 프로세스 kill 포함)
$ sudo $(which python) mini_dash_tui.py

------------------------------------------------------------------------

5. 주요 조작 키 (Key Bindings)

| 키 | 기능 |
| :--- | :--- |
| ↑ / k | 커서 위로 이동 |
| ↓ / j | 커서 아래로 이동 |
| SPACE | 프로세스 선택 / 선택 해제 |
| t | 선택된 PID에 SIGTERM 시그널 전송 (우아한 종료 요청) |
| x | 선택된 PID에 SIGKILL 시그널 전송 (강제 종료) |
| i | 선택된 PID에 SIGINT 시그널 전송 (인터럽트) |
| c | 모든 선택 해제 (Clear) |
| r | 즉시 새로고침 (Refresh) |
| q / ESC | 프로그램 종료 |
| s | 정렬 기준 토글 (CPU% <-> RSS 메모리) |
| f | 사용자 이름으로 필터링 입력 |
| a | 사용자 필터 해제 (All users) |
| v | 타입 필터 순환 (All -> ipynb -> python) |
| 0/1/2 | 타입 필터 직접 선택 (0:All, 1:ipynb, 2:python) |
